### Notion / Super (2020-?)

![Woof!](/images/journal/notion-super-blogging/03-screen_shot_2020-11-22_at_09-32-06.jpg)

*Woof!*

My writing tapered off immensely in recent years, and I didn't find [my old site built with Jekyll](https://github.com/qrush/qrush.github.com) to be interesting to work on anymore. I've now swung back to the land of a managed platform that frees me from:

* Worrying about Ruby dependency updates *(No JavaScript, what a concept!)*
* An ancient CSS template that still uses 960.css *(and fully learning flexbox still, sorry I haven't done this yet)*
* Needing to think about mobile design / accessibility *(I hope Notion is doing so...)*
* Having to jump to GitHub (or my editor) to make changes. *(Now it's all in browser!)*

I haven't switched my entire blog over, as most of my [⏳Archive](https://quaran.to/archive) is hosted on other sites. Since the majority of the posts were on external sites I didn't feel beholden to correct URLs that may be broken, but I may do that too soon!

I've been using [Super](https://demo.super.so/) to host my site off [Notion](https://www.notion.so/), which is only $4/month and allows me to stop worrying about all of the above. I get a great little writing and note-taking platform that allows for HTML import + export, and then Super scrapes all of that and wraps it up in a beautiful CDN-enabled package for any internet denizen to browse.

## The end game

So one might think: what happens when Super, or Notion, breaks this setup or disallows publishing? Yes, that's a risk I have assumed with this project. I can export any Notion document as HTML or Markdown, so once this setup stops working I'll just move on, just like I did twice before. This time it'll cost $4/mo for the time being, but honestly that's motivation to get me to write more. I guess we'll see in a few years!
