# Written elsewhere

I tend to write/blog a lot. Here's where my writing has ended up outside of
this site.

### Git Ready

[![git ready](/images/gitready.png)](http://gitready.com)

A knowledge base about Git that focuses on learning things "one commit at a
time". With over 50 tips and several translated sites, it became a great
resource for those both new and old to the version control system.

### GitHub Rebase

[![GitHub Rebase](/images/rebase.png)](https://github.com/blog)

A biweekly roundup about the latest and greatest projects coming out of
[GitHub](https://github.com), posted on the GitHub blog.
